# BrightRoot Dental – HTML Template
Static HTML/CSS/JS template for a dental clinic (no build step, no dashboard).

## Run
Open `index.html`, or `python3 -m http.server` and visit http://localhost:8000.

## Customise
- Colours/spacing/fonts: CSS variables at top of `assets/css/style.css`; dark theme in `dark-mode.css`; RTL in `rtl.css`.
- Content: edit `pages/*.html` directly (or edit `build_pages.py` and run `python3 build_pages.py`).
- Search for `TODO` to find: Formspree form id, Google Maps embed, Mailchimp action, domain in `sitemap.xml`/canonical, images (`assets/images`, use WebP).

## Pages
Home, Services, Doctors, Gallery, Reviews, About, Contact (appointment form + map), 404, Coming Soon.
